# Version 10.4 — Simplified valuation-focused application

At the user's request, FairScope is now focused on individual-stock and batch fair-value research.

## Removed

- Portfolio Risk workspace and sidebar option
- Transactions & Performance workspace and sidebar option
- Holdings, P&L, XIRR, TWR and transaction-import workflow
- Portfolio allocation, contribution, VaR, diversification and stress sections from batch reports
- Portfolio and transaction supporting modules, templates, samples and dedicated tests

## Retained

Stock valuation, scenarios, governance/order-book/promoter analysis, sensitivity, Monte Carlo valuation uncertainty, watchlists, alerts, filings, data lineage, model audit, batch valuation, assumptions review, financial-company review, external cited review, cache, diagnostics, privacy and detailed PDFs remain available.
